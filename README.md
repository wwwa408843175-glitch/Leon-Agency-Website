# Leon – Creative Agency Website

## Project description
Leon is a responsive, single-page creative agency website built with **HTML5** and **CSS3**. It presents an agency introduction, features, services, portfolio projects, an about section, and contact information.

## Project files
- `index.html` — the complete website, including its HTML structure and CSS styling.
- `README.md` — project description, features, and instructions.

## Main sections
1. **Header:** agency logo and dropdown navigation links.
2. **Landing:** welcome message over a background image.
3. **Features:** three introductory benefits.
4. **Services:** graphic design, UI/UX, web design, and web development.
5. **Portfolio:** three sample project cards.
6. **About:** agency description and image.
7. **Contact:** email link and social media icons.
8. **Footer:** copyright information.

## Technologies used
- HTML5 for page structure and semantic elements.
- CSS3 for layout, colors, spacing, hover effects, and responsive design.
- Google Fonts (Work Sans) for typography.
- Font Awesome 6.4.0 for icons.
- Unsplash for illustrative photographs.

## How to run the project
1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html`, or open it using a browser.
4. An internet connection is required to load the external font, icons, and images.

## Responsive design
CSS media queries adjust the layout for desktop, tablet, and mobile screens. The navigation menu opens on hover or keyboard focus.

## Notes
- The social media links are placeholders (`#`). Replace them with real account URLs before publishing.
- The email address is a sample contact address. Replace it with the correct address if the project is used for a real agency.
- Images, Google Fonts, and Font Awesome are loaded from external services, so they may not appear without an internet connection.

## GitHub upload instructions
1. Sign in to [GitHub](https://github.com/).
2. Create a new repository (for example: `leon-agency-website`).
3. Upload `index.html` and `README.md` to the repository.
4. Commit the files.
5. To publish the website, open **Settings → Pages**, select the `main` branch and `/ (root)` folder, then save.
6. GitHub Pages will provide a public website link after deployment.
